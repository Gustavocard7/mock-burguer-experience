# Publicação no Render

O painel do Render está autenticado no workspace do usuário e reconhece o repositório privado `Gustavocard7/mock-burguer-experience` no branch `main`. A criação selecionada é um **Static Site**; para o projeto Vite, a configuração planejada é `pnpm run build` como comando de build e `dist/public` como diretório de publicação. Fonte: painel do Render em `https://dashboard.render.com/static/new`, consultado em 2026-08-26.
